# DLWISE – Deadline Wise

## Student Deadline Management System

DLWISE (Deadline Wise) is a student-focused deadline management system developed using C++ and Object-Oriented Programming concepts. The system helps students organize academic deadlines, assignments, events, and important tasks in one place.

## Project Objective

The main objective of DLWISE is to help students manage their academic deadlines efficiently and reduce the chances of missing important tasks.

## Features

- Add academic deadlines
- View upcoming deadlines
- Organize tasks according to deadlines
- Update deadline information
- Delete completed or unnecessary deadlines
- Display task information in an organized manner
- Simple and student-friendly interface
- Object-Oriented Programming implementation

## Technologies Used

- Programming Language: C++
